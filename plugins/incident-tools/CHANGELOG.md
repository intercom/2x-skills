# Changelog

All notable changes to the `incident-tools` plugin are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.0] - 2026-11-10

### Added

- Initial release of the `incident-tools` plugin.
- `five-whys` skill — builds a five-whys causal chain from impact to actionable root cause, with every factual claim checked against a primary source by fact-checker subagents and every causal link attacked by a cynic subagent before the analysis ships.
